# Klingenhort

16-Bit Hack & Slash im Browser – für Handy (Querformat) und PC. Als App installierbar und offline spielbar.

**Spielen:** https://katimur94.github.io/klingenhort/

## Features
- Animierte Pixel-Sprites mit leichtem 3D-Effekt (Drehung, Schräglage, Stauchen, Schatten, Tiefe)
- 3er-Kombos, Wut-Leiste und Spezialangriffe je Waffe (Wirbelklinge, Erdbeben, Schattenschritt, Pfeilsturm)
- Dolche, Schwerter, Äxte, Bögen und Rüstungen in fünf Stufen; Beute in fünf Seltenheiten mit Zusatzwerten
- Goblins, Skelette, Echsenmenschen, Orks, Oger, Imps, Hornteufel, Nekromanten, Mimiks und drei Bosse
- Explosionen, Fallen, zerstörbare Kisten, Truhen, Licht und Schatten, Chiptune-Musik
- Level-System, Gegner werden mit jeder Stufe stärker; Spielstand im Browser, übertragbar per Code

## Steuerung
- **Handy:** linke Hälfte ziehen = laufen · Angriff halten · ROLLE ausweichen · SPEZ Spezialangriff · WAFFE wechseln · TRANK heilen
- **PC:** WASD/Pfeile · J/Leertaste/Klick angreifen · K/Shift/Rechtsklick ausweichen · F Spezial · Q/E Waffe · H Trank · Esc Pause

## Als App installieren
- **Android (Chrome):** Seite öffnen → „Als App installieren“ im Titelmenü oder Menü → „App installieren“
- **iPhone (Safari):** Teilen → „Zum Home-Bildschirm“
